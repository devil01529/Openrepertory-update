# Open Repertory 1.30

Open Library → a remedy → Read → Jump to section. A compact picker matching the app theme replaces the Android dropdown. Search headings or scroll, then tap a section to jump to it. The selected section has a checkmark. X, Back or Escape closes without changing the reading position; choosing a section focuses its heading.

Switching the historical source rebuilds the list from that source’s headings. Existing source text, private notes and case links are retained.

Install over the existing app, or use ⋮ → App updates. Do not uninstall.
