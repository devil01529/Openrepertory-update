Open Repertory 1.29 — A focused Materia Medica workspace

Removed the routine backup reminder and case-status strip from the top. Switch patient or case from Today’s consultation card; backups remain in the menu and Today.

Materia Medica now has a compact searchable browser and Read / Case links / My notes views. Read starts with the historical source; choose an author and jump directly to a source section. Case links contains statistics, analysis and related-rubric actions. Private notes and existing clinical functions are retained.

Same Android package and signing identity. Install over your existing app.
