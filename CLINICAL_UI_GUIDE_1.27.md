# Open Repertory 1.27 — glass interface guide

Install over your existing app. Do not uninstall or clear storage. Open **⋮ → App updates → Check for updates → Download update → Install update**, or download the APK from the public GitHub release.

## What changes
The shared header, tools menu, navigation dock/tablet rail and Analysis tabs now share a rounded glass-inspired appearance. Today cards, chapter selection, repertory picker, patient cards, dialogs and action buttons use coordinated highlights, borders and shadows. Light, dark and automatic themes remain available in **⋮ → Settings → Appearance**.

Long patient/case names wrap inside the Today card without changing saved text. On short screens, the top context switch abbreviates long labels to leave reading space; open that switch or Today for full names.

Clinical text stays on opaque reading surfaces. Rubric wording, remedy spacing and grades, matrix colors, analysis methods and patient workflows are retained. Chapter pictures, whole-drawer scrolling and the icon-only floating clipboard remain available.

## Glass effects and text size
Open **⋮ → Repertory & reading**.

- **Glass effects** enables a soft static blur on supported navigation surfaces. Turn it off for solid controls. Your choice is saved on this phone. Older Android WebViews automatically use the solid appearance, even when the switch is on.
- **A− / A+** resize text from 80% to 140%; **Reset** returns to 100%.
- Show/hide remedies, expand/collapse branches, Patient words and Reading density & privacy remain in this section.

Glass effects never blur rubric lists, remedy grades, patient forms, analysis values or the presentation privacy shield. Supported system reduced-transparency/high-contrast preferences also use solid chrome. Reduced-motion mode disables the new transitions. These system preferences depend on your Android/WebView version; the in-app switch works independently.

## Access, records and updates
Your existing approved account and encrypted records are retained. Warm background returns while the phone stays unlocked retain the open page and case; owner approval refreshes quietly. Device locking secures clinical access. A cold start or an Android-killed process still initializes and verifies access. Owner approval controls and the existing update system are unchanged.
