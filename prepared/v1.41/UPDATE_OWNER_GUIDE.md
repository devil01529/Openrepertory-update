# Open Repertory 1.41 — update screen guide

Install this update over the existing app; do not uninstall it. The package and signing identity are retained.

1. Open the main menu → App updates.
2. Choose Check for updates. If an update is available, use Download update.
3. A progress bar and percentage show download progress. Inactive download/check actions are hidden while work is running; Cancel download / check stops the current operation.
4. After verification completes, choose Install update and confirm Android's installer prompt. If Android requests installation permission, allow Open Repertory, return and tap Install update again.
5. What's new opens full, scrollable release notes. Back returns to the controls. Close dismisses the screen; Cancel is the explicit transfer cancellation action.

The update screen follows the app's saved Light/Dark/Auto theme and Visual effects → Glass effects preference when opened. It uses lightweight rounded gradient materials; it does not capture your clinical screen or run a continuous blur animation. Turning glass off gives solid surfaces. Android's own installer and system permission screens cannot be restyled by this app.

Users on 1.40 or earlier will see the old download screen while installing 1.41. The new screen appears after 1.41 is installed and reopened.

All existing repertories, remedy grades, Materia Medica, scoring, patient/case records and approval remain retained. New online source candidates were researched but not added without complete proofreading. See REPERTORY_SOURCE_REVIEW_1.41.md for the evidence and remaining work.

The native update screens use bundled Noto Sans (SIL Open Font License, included in the APK) so a device-selected decorative font does not replace the update text.
