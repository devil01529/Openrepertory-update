Open Repertory 1.41 — native glass update screen

The Android App updates screen now matches the app's glass visual style: rounded light/dark surfaces, readable sans-serif text, native ripple buttons and a visible percentage during downloads. The native dialog follows the saved app theme and Glass effects setting. Full release notes remain separately scrollable, keeping download controls compact.

Download, verification, cancellation and Android-confirmed installation retain the same signed manifest, APK hash, package and certificate checks. Clinical data, scoring, encrypted records and approval are retained. Android's own installation permission and confirmation screens remain controlled by Android.

Additional online repertory databases and historical scans were researched. No candidate passed complete proofreading for this release, so no uncertain data was added and existing books are unchanged. Findings and import criteria: https://github.com/devil01529/Openrepertory-update/blob/main/REPERTORY_SOURCE_REVIEW_1.41.md

The native update screens use bundled Noto Sans (SIL Open Font License, included in the APK) so a device-selected decorative font does not replace the update text.
