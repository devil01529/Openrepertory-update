Open Repertory 1.28 — Reading controls where you need them

Open Repertory and tap “Aa Repertory & reading” beside the book name. Text size, remedies, branches, patient words, density/privacy and glass controls now live here, outside the main menu. The button appears only on Repertory.

A short, lightweight panel entrance respects reduced motion. Small-screen scrolling, focus return and repeated Back/close navigation have been tested. Existing saved preferences and clinical functions are retained.

Install over your existing app. Same Android package and signing identity.
