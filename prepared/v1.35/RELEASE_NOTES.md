Open Repertory 1.35 — library cleanup and a new proofread Materia Medica source

Removes Clarke, Knerr and Boger repertories from the chooser and APK data. Saved cases retain original rubric text, remedies, grades, importance, source identity, snapshots and analysis. Opening an old case uses an available repertory for browsing; saved source details remain accessible without downloading the removed book.

Adds C. W. Wolf’s complete Apis Mellifica (1858) as a separate Materia Medica source: 12 original sections, complete text, attribution and Project Gutenberg licence. Existing Materia Medica passages are retained. This is one Apis monograph, not a new broad multi-remedy volume.

Kent and all seven remaining repertory databases are unchanged. Online replacement candidates were researched, but none was bundled without a verified source-rights and content audit. Research and validation reports accompany this update.

Existing package/signing identity, Apper access, encrypted storage and five-version release retention remain in place.
