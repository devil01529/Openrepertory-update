Open Repertory 1.22 — clinical workspace redesign and audited English Kent

Major clinical UI redesign: consultation-first Today, patient/case context switcher, compact repertory controls, optional patient-word finder, source details and references, reading density and remedy previews, Selected/Ranking/Matrix analysis views, adaptive tablet panes, patient Overview/Visits/Cases/Notes, focused library, private remedy notes and presentation mode. The floating Analysis shortcut now shows only a clipboard icon. Short landscape layouts reserve an icon slot instead of covering rubric controls. Workspace Back navigation and reading-position restoration are included.

Adds the actual OOREP English Kent source separately from legacy Repertorium Publicum. All 68,742 original source IDs, paths and 624,010 remedy records/grades were compared exhaustively against 688 API pages. The 37 chapter index rows and 1,039 generated navigation headings are identified separately. Existing Publicum clinical data, saved source keys, case weights and selections are retained.

Adds five explicit Kent cross-reference occurrences and 103 source-recorded alternate remedy names to navigation/search. These alternate names are remedy synonyms; no unsupported rubric equivalences are invented. Publicum receives three reference occurrences and its 229 dictionary alternate names via a metadata sidecar. The two conflicting source versions of “clenching, fingers” remain labelled with their own grades; a case cannot select both.

Same Android package/signing identity, no new permissions. Existing approval and encrypted records remain required. Analysis scoring is retained; this is an electronic source audit, not printed-book scan certification.
