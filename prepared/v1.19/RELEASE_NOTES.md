Open Repertory 1.19 adds free in-app updates.

- Open the three-dot menu → App updates to check, download and install a newer APK.
- Background checks run after the workspace opens, at most once a day.
- Signed update information and APK identity checks protect the installation flow.
- Android asks for installation permission and final confirmation.
- Existing Apper login, owner approvals, repertories and encrypted records are retained.

Install this APK over your existing app. Do not uninstall or clear app storage. This first updater-enabled version needs one manual installation; later releases can be downloaded from inside the app.
