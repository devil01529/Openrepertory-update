# Open Repertory 1.39 — glass interface guide

Install over the existing app using **⋮ → App updates → Check for updates**. Keep app storage and the existing installation.

The five destinations now sit in an inset floating capsule on phones and a rail on tablets. The selection highlight follows navigation, with short transitions for tools, sheets and chapters. Rubric text, original grades, notes and matrix cells retain opaque reading surfaces. Chapter pictures and the clipboard shortcut remain.

Open **⋮ → Settings → Visual effects** to change **Glass effects** or **Reduce motion**. Changes save immediately on this phone. Turn Glass effects off for solid navigation. Reduce motion removes decorative movement; system motion/transparency preferences are also honored where the WebView exposes them. Older WebViews use solid materials automatically when backdrop blur is unsupported.

**Repertory & reading** remains a button inside Repertory. Its text-size, remedy visibility, branch and reading/privacy controls retain their placement. Its Glass effects switch mirrors the global setting.

Touch use no longer leaves large focus outlines on buttons. Keyboard navigation still shows a focus ring. Dialogs remain scrollable, close immediately with Back, and adapt to the visible viewport.

This is an original Android/WebView adaptation inspired by Apple's material guidance. It does not use Apple's native optical renderer. Database content, scoring, encryption, remembered approval, device locking, screenshot rules and signed updates are unchanged.
