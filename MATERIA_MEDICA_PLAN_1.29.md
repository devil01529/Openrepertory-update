# Materia Medica improvement plan — 1.29

## Phase 1: Reclaim the workspace (implemented)
Remove the routine top backup reminder and the global patient/case status strip. Keep patient/case switching inside the Today consultation card. Keep backups in the main menu and Today records card. Preserve actionable draft and interrupted import/export recovery prompts.

## Phase 2: Improve remedy discovery (implemented)
Use one Materia Medica heading with Compare remedies. Combine search, clear-search action, sorting and source-text filtering. Show remedy name and abbreviation together, with source availability and private-note labels. Move rubric totals into the detailed Case links view. Retain lazy list pagination, alias search, source-loading retry and existing sorts.

## Phase 3: Prioritise reading (implemented)
Open profiles on Read, with historical source attribution and source text. Put repertory statistics, case evidence, Analysis and related-rubric actions under Case links. Put editable private notes under My notes. Add keyboard-accessible tabs with persistent selection during profile refresh. Switching remedies starts on Read.

Provide a source section picker generated from actual headings. Rebuild it when the author/source changes. Keep original source records unchanged. Preserve reader/list scrolling and Back navigation. Use clear selected-author contrast and readable line spacing, with no animated text reflow.

## Phase 4: Verify and deliver (implemented)
Test phones, landscape and tablets in light/dark themes with enlarged text. Verify search, source filters, tabs, source switching, section jumps, private notes across reload, Today case switching, backup access and interrupted-work recovery. Run clinical, source-identity, menu, scrolling and record-reliability regressions. Verify the APK identity, unchanged clinical data and signed update metadata before delivery.

## Later improvements (not included in this release)
- Search within the selected source with explicit match counts and accessible next/previous controls.
- Clinician-tested typography presets and optional source bookmarks.
- Device frame-time measurements before adding more animated effects.
