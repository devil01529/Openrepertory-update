A cleaner, easier-to-use menu.

- Seven grouped actions on phones instead of a long list of thirteen.
- Matching line icons, shorter labels and clearer clinical/app sections.
- Home, Search, Case, Patients and Library remain in the bottom navigation.
- Appearance and Online AI are together in a compact Settings view.
- Account & access, Backup & restore and App updates stay directly accessible.
- Close, keyboard navigation and Android Back behave consistently.
- Small screens, landscape, dark mode and large text are supported.

Existing repertories, patient records, analysis, login and owner approvals are retained. No clinical database or Apper backend changes.

From version 1.19, open the old menu → App updates → Check for updates → Download update → Install update. Allow installation from Open Repertory if Android asks, return and tap Install update again, then confirm Update. Do not uninstall or clear storage.
