# Open Repertory 1.38 — graded historical repertory and full result access

Adds Guernsey — Haemorrhoids, from the public-domain second edition (1892), as a structured offline database. Includes the complete repertory section, printed pp. 121–140: three original sections, 518 source entries, 222 remedy-bearing entries, 138 identified remedies, 1,825 scored associations and 316 See/Compare links. There are 38 additional navigation headings. Existing approved chapter artwork is used for sensations, objective findings and modalities.

All twenty repertory pages received AI-assisted scan comparison. Plain, italic and bold type retain grades 1, 2 and 3. Four ambiguous printed remedy occurrences remain visible with their original grade and are excluded from scoring; identities are not guessed. This review is not independent clinician certification. The separate remedy-first Materia Medica portion is outside this repertory import.

Removes the analysis display cutoff of 120 remedies. Ranking and Matrix now search every scored remedy and offer first/previous/next/last pages plus page-number entry. Display batches contain 24 remedies; all results remain accessible. No arbitrary rubric-selection count cap is imposed. Recorded grades excluded by the current grade filter remain distinguishable from absent associations. The scoring explanation opens on demand.

Fixes an existing older-Android Keystore issue that could write incomplete ciphertext for large case records. Encryption/decryption now collect bounded outputs and reject inconsistent lengths before committing a write. Existing keys, IV/AAD format, transactional rollback and recovery protections remain; previously damaged ciphertext still requires backup recovery.

The seven existing repertory databases, including Kent, Materia Medica, artwork, scoring formula, record format and native access/update protections are retained. Same package and signing identity; no new Android permissions. Install over the current app and keep its storage.

This specialist work is distinct from modern Synthesis and Complete Repertory, which are not bundled. No PDF reader, standalone database asset or ZIP is supplied.
