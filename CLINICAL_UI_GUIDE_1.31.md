# Using the new repertories — 1.31

1. Open Repertory and tap the book name. Choose Boericke, BBCR or Therapeutic Pocket Book — Allen 1891.
2. Select a chapter or search a rubric/remedy. Alternate remedy names supplied by the source also work.
3. Tap a reference link to jump to its resolved entry. When the destination is ambiguous, search opens so you can choose it.
4. Use the source information button to inspect the source and notes. Unscored/conflicting entries are explicitly labelled and excluded from analysis.
5. Add rubrics to your case as before. Grades 4 and 5 retain their numeric values in analysis, saved snapshots and encrypted backups. Grade scales differ between books.
6. For an older saved case, “Earlier editions” contains the previous BBCR OCR and 1846 TPB sources. Existing case entries retain their original source and grades; the app does not silently migrate them.

Kent is unchanged. TPB's provider marks the 1891 edition under development. See REPERTORY_COMPARISON_1.31.md for measured coverage and source limitations. Phatak, Synthetic and Complete are not bundled because no authorized structured export was available.

Install through Menu → App updates, or download the signed APK from the GitHub release. Android asks you to confirm installation. Keep an encrypted backup before any update; retain the existing installed app rather than uninstalling it.
