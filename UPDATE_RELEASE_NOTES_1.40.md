# Open Repertory 1.40 — clinician workflow improvements

- Consultation review on Today and in Clinical tools: case context and direct patient, visit, analysis, reference, snapshot and backup actions.
- Case-specific recent searches with original book/chapter scope and safe cancellation.
- Fixes continued chapter searches silently widening to the whole book.
- Hidden remedy lists build no remedy buttons; showing them retains original grades and complete associations.
- Materia Medica Find in text, Previous/Next and Clear, with visible controls and edition-specific results.
- Materia Medica case links open exact original books/rubrics; related-rubric finding explicitly uses whole-book scope.
- Reading-setting save failures retain previous values and allow retry. Presentation mode protects review/history.

All repertory/Materia Medica content, scoring and native security code are retained. Same signing identity; no new permissions. Install over the current app.
