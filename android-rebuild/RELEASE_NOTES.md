Similora 2.0.0 is a new independent Android app with the existing clinical interface and eight bundled repertory workflows, Materia Medica, analysis, glass reading controls, encrypted records and backups.

Sign in using your Similora website account. The website owner approves or removes access through Account & access inside the app. Select the 30-day remembered session on your private phone to avoid repeated password entry. Internet is required for access checks.

IMPORTANT: this uses a new Android package and signing identity. It installs alongside Open Repertory; it cannot update the old package or automatically read its encrypted records. Keep the old app, export an encrypted backup, import it into Similora and verify your records before uninstalling anything.

Optional online Gemini still requires your own API key. Offline symptom finding is retained. Screenshots are allowed while active unless disabled in Mobile security; background and locked screens are protected.

See android-rebuild/README.md and TEST_REPORT.md in the repository for migration, build instructions and the precise verification scope. Do not assume every phone, printer or backup migration has been tested.
