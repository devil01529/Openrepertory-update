# Open Repertory 1.29

The highlighted backup reminder and case-status strip have been removed from the top of the app. Use Today → Switch patient or case to change context. Backups remain under ⋮ → Backup & restore and in Today’s records card. Recovery prompts still appear for interrupted work.

Open Library to browse Materia Medica. Search by remedy name, abbreviation or source-recorded alias; use × to clear the query. Text only filters remedies with bundled source passages; Show all restores the complete list. Sorting and the notes-only list remain available. Compare remedies opens the existing comparison workspace.

Open a remedy, then choose:
- Read: historical text, author/source selection and Jump to section.
- Case links: repertory statistics, current-case evidence, Open analysis and related rubrics.
- My notes: editable private notes saved on this phone and included in encrypted backups.

Back returns to the remedy browser with its query retained. Notes survive source and view changes. Different remedies open on Read. Empty source entries remain explicitly labelled; no source passages are invented.

Update using ⋮ → App updates, or install the new APK over the existing app. Do not uninstall first.
